## 1. The Task
The task of this laboratory work is to take the context-free grammar from Variant 7 and transform it step by step into Chomsky Normal Form (CNF), while preserving the language generated by the grammar. The conversion is done in the exact order required by the assignment: eliminate epsilon productions, eliminate renaming (unit) productions, eliminate inaccessible symbols, eliminate nonproductive symbols, and then obtain the final CNF grammar. In this lab, the initial grammar is defined over nonterminals {S, A, B, C, E}, terminals {a, b}, and productions including S -> bA | B, A -> a | aS | bAaAb, B -> AC | bS | aAa, C -> epsilon | AB, and E -> BA.

Epsilon elimination is implemented by first computing the nullable set and then generating all valid combinations obtained by removing nullable symbols from each production. This is the key mechanism that replaces rules such as C -> epsilon while preserving derivations that depended on C being nullable.

```python
nullable: Set[Symbol] = set()
changed = True
while changed:
    changed = False
    for lhs, rhs_set in g.productions.items():
        if lhs in nullable:
            continue
        if tuple() in rhs_set:
            nullable.add(lhs)
            changed = True
            continue
```

Unit-production elimination computes closure pairs A =>* B where each step is a renaming rule, then copies only non-unit productions from reachable B into A. In this way, chains like S -> B are removed, but the useful productions of B are retained under S so the language remains equivalent.

The CNF conversion then enforces the two legal CNF production forms. If terminals appear inside long productions, they are replaced by new helper nonterminals T_i that produce one terminal each. If a production has length greater than two, it is broken into binary rules using fresh helper symbols X_i until every right-hand side has exactly two nonterminals.
